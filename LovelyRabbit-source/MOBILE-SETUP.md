# 把兔兔要减肥安装到小米手机

这是 PWA：先把网页发布为 HTTPS 网站，再通过手机浏览器安装到桌面。无需 APK、应用商店、后端或手机上的 Node.js。发布完成后，电脑关机也能使用。

## 1. 先保存现在的记录

在电脑正在使用的应用中，设置 → 导出 JSON 备份，确认下载完成。如果没有下载文件，使用“查看与复制完整备份”保存全部文本。

电脑 localhost、正式网址、不同手机和不同浏览器的本地数据相互独立。上线不会自动把电脑记录转到手机；需要把备份文件传到手机后导入。

## 2. 在电脑上传现成部署包

1. 使用交付目录 `outputs/LovelyRabbit-pages.zip`，这是已经构建好的静态部署包，不需要重新安装依赖。
2. 登录 [Cloudflare Dashboard](https://dash.cloudflare.com/)。
3. 打开 **Workers & Pages** → **Create application / 创建应用**，进入 **Pages** 的 **Get started / 开始**，选择 **Drag and drop / 拖放上传**。不要选择需要代码入口的 Worker 项目。
4. 填写一个项目名，例如 `beauty-quest-diary`，上传 `LovelyRabbit-pages.zip`，点击 **Deploy site / 部署站点**。
5. 等部署成功后，复制平台实际提供的 HTTPS 网址。不要猜测或照抄示例域名。打开网址检查首页、日历、商店和设置。

ZIP 根目录已包含 index.html、assets、sw.js、manifest.webmanifest 和图标。不要上传源码包 `LovelyRabbit-source.zip`，也不要额外套一层目录。以后更新，在同一个 Pages 项目里创建新的 production deployment、上传新版静态包，保持正式域名不变。

官方说明：[Pages Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/)（支持 ZIP 或文件夹，界面标签可能变化）。本次尚未替你登录或执行真实发布。

## 3. 手机打开并添加到桌面

先把正式网址通过聊天或其他方式发到手机，复制后在手机浏览器中直接打开；不要停留在聊天软件内置网页中。首次保持联网直到首页正常加载。

**小米 Civi 4 Pro / HyperOS 自带浏览器：**打开同一正式网址 → 浏览器菜单 → 找“添加到桌面”“添加到主屏幕”等选项并确认。具体菜单及是否独立窗口运行取决于实际浏览器版本，本次没有真机确认。

**Android Chrome：**打开正式网址 → 右上角 ⋮ →“添加到主屏幕”→“安装”（也可能直接显示“安装应用”）。从桌面的“兔兔要减肥”图标启动。如自带浏览器只创建快捷方式或离线不稳定，可改用 Chrome。官方说明：[Chrome 安装网页应用](https://developer.chrome.com/blog/how_chrome_helps_users_install_the_apps_they_value)。

手机上的 localhost 指的是手机自身，不能使用电脑的 `http://localhost:5173/`。也不要直接双击解压出来的 index.html；正式 PWA 需要通过 HTTPS 网站运行。

## 4. 把记录迁移到手机并验收

1. 把第 1 步保存的 JSON 文件传到手机。
2. 在选定的手机浏览器/桌面应用中：设置 → 导入并恢复备份 → 选择文件 → 查看确认弹窗 → 确认恢复。恢复会替换该浏览器当前数据；若手机已记录内容，也先导出一份。
3. 核对昵称、积分、心愿、日历、日记与体重是否一致。
4. 打卡一次，关闭应用再从桌面打开，确认记录保留。
5. 开飞行模式，重新从桌面进入，检查能打开、查看记录并继续打卡。恢复联网后检查一次。
6. 重启手机后再打开检查。此步骤必须用你的真机完成，电脑模拟测试不能替代。

## 日常使用

- 日历只展示已完成记录；最近 3 天漏记时，选中日期，点击“补录打卡”。
- 记录保存在所用浏览器中，不会自动云同步。定期导出 JSON，尤其换手机、换浏览器、换域名、清理或卸载之前。
- 可申请“浏览器持久存储保护”，但是否授予由浏览器决定；它不能代替备份。
- 先固定一个正式域名和一个常用浏览器使用。不同浏览器的数据不共享，正式版网站更新不会主动清除 IndexedDB。
- 若手机网络打不开正式网址，先核对网址和网络，再决定是否使用可访问的自定义域名；本机测试不能保证所有地区的实际访问情况。
